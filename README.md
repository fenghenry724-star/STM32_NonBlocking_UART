# STM32非阻塞状态机与上位机通信系统 (STM32 Non-Blocking UART & State Machine)
## 本人声明
本人为嵌入式开发小白，这个项目仅为学习过程使用的入门演示项目，也可供大家使用学习，同时欢迎大佬批评指正。

## 项目简介
此项目基于STM32F103ZET6系列开发，使用HAL库，核心实现了基于时间戳的非阻塞按键扫描，以及基于USART串口中断的指令接收与解析。通过自定义简单的字符串协议，实现上位机对底层硬件的实时控制。

## 开发环境
*   **主控芯片**：STM32F103ZET6
*   **开发工具**：STM32CubeMX, Keil MDK(V5)
*   **调试工具**：USB转TTL模块、串口调试助手
*   **通信参数**：USART1，115200波特率，8位数据位，1位停止位 (8N1)

## 核心功能
1. **串口重定向**：重写`fputc`函数，将标准库的`printf`重定向至串口USART1，将单片机产生的信息打印到电脑屏幕，方便调试。
2. **中断接收与接力**：配置`HAL_UART_Receive_IT`开启接收中断，在`HAL_UART_RxCpltCallback`回调函数中逐字节拼接字符串，并在函数末尾**重新开启中断**，防止丢包。
3. **非阻塞按键扫描**：摒弃`HAL_Delay`卡死的延时方式，利用`HAL_GetTick()`获取系统毫秒级时间戳进行软件消抖。
4. **协议解析**：接收完整指令帧后，进行指令匹配，精准控制底层GPIO状态，并回传系统状态。

## 实现效果
1. 持续在电脑屏幕打印"Hello PC!"
2. 当串口收到'a'的时候，改变灯的亮灭状态，并且返回"收到'a', 灯已翻转！"

## 编译与运行指南
为了保持仓库轻量化，本仓库**仅上传了应用层核心代码（`Core`）、CubeMX 配置文件（`.ioc`）与 Keil 工程文件（`.uvprojx`）**，未包含体积庞大的自动生成库（`Drivers`）。

**若需在本地直接编译，请遵循以下步骤：**
1. 克隆或下载本仓库。
2. 使用 **STM32CubeMX** 打开目录下的 `.ioc` 文件。
3. 点击 `GENERATE CODE` 重新生成底层驱动库（`Drivers` 文件夹会自动生成）。
4. 使用 **Keil MDK** 打开 `.uvprojx` 工程文件，即可直接编译并烧录。
